## ✅ РАЗДЕЛ 3: Подтверждение опасных действий (update/delete) через UI

### Требование
1. Если модель (агент) хочет **изменить** или **удалить** данные, она:
   - вызывает специальный tool, который **не выполняет действие сразу**, а:
   - рендерит на фронтенде UI‑элемент с вопросом и кнопками «Да» / «Нет».
2. На фронтенде:
   - показывается блок/карточка/модалка от этого tool:
     - текст: что именно собираемся сделать (например: *"Вы уверены, что хотите удалить сообщения треда X?"*);
     - кнопки **Да** / **Нет**.
   - При нажатии:
     - **Да**: вызывается другой tool или тот же с параметром подтверждения, который **реально выполняет операцию** (update/delete).
     - **Нет**: отправляется в чат ответ, что действие отменено.

### Проверка

#### ✅ 3.1: Tool для запроса подтверждения (не выполняет действие)
- ✅ **requestDangerousActionConfirmation:** Client-side tool, который только показывает UI
  - Не имеет execute функции (client-side)
  - Принимает параметры: `action`, `targetId`, `threadId`, `newContent`, `xlsxValue`, `question`
  - Возвращает `decision: "yes" | "no"`

**Файлы:**

**Статус:** ✅ **ВЫПОЛНЕНО**

  - Стилизованную карточку с рамкой

**Файлы:**

## 📝 Дополнительные детали реализации

### Client-side tools
- **askForConfirmation:** Универсальный tool для любых подтверждений
- **getLocation:** Автоматически выполняется с случайным городом (для демонстрации)
- **requestDangerousActionConfirmation:** Специализированный tool для опасных действий
- **openTable:** Открывает таблицу сообщений в UI

### Подтверждение опасных действий
- **Двухэтапный процесс:**
  1. Модель вызывает `requestDangerousActionConfirmation` → показывается UI
  2. Пользователь нажимает "Да" → модель получает `decision: "yes"`
  3. Модель вызывает `performDangerousAction` → операция выполняется
- **Безопасность:** Операции выполняются только после явного подтверждения пользователя
- **UI обновление:** Все изменения отображаются без перезагрузки страницы

### Интеграция с таблицей сообщений
- **Редактирование:** Кнопка "✏️" в таблице → отправка команды модели → подтверждение → обновление
- **Удаление:** Кнопка "🗑️" в таблице → отправка команды модели → подтверждение → удаление
