# ChatGPT-lite

Упрощённый аналог интерфейса ChatGPT с тредами, хранением сообщений в базе и **генеративным UI** на основе Vercel AI SDK.

## 🚀 Быстрый старт

```bash
# 1. Установить зависимости
bun install

# 2. Создать .env.local с API ключом OpenAI
echo "OPENAI_API_KEY=your_key_here" > .env.local

# 3. Запустить проект
bun run dev
```

Откройте http://localhost:3000 в браузере.

## 📋 Техническое задание

### Цель
Сделать упрощённый аналог интерфейса ChatGPT с тредами, хранением сообщений в базе и **генеративным UI** на основе Vercel AI SDK.

### Стек и общие требования

**Обязательный стек:**
- **Next.js 16** (App Router, TypeScript)
- **Vercel AI SDK UI**:
  - `useChat`: https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat
  - Generative UI / tools: https://ai-sdk.dev/docs/ai-sdk-ui/generative-user-interfaces
- **Bun 1.3+** — использовать встроенную базу (sqlite через Bun), для хранения:
  - тредов;
  - сообщений.
- Frontend: React/Next, Tailwind/любая простая стилизация — **по желанию**.

**Общие пожелания:**
- Аккуратный, читаемый TypeScript.
- Структура проекта, близкая к production (разделение слоёв API / UI / DB).
- Краткое README с описанием запуска.

## 📋 Реализованные функции

#### ✅ 1. Чат с тредами
- ✅ Список тредов в сайдбаре слева
- ✅ Создание нового треда
- ✅ Переключение между тредами
- ✅ Загрузка истории сообщений из БД при переключении
- ✅ Streaming ответы от модели (SSE)
- ✅ Сохранение всех сообщений (user и assistant) в SQLite

#### ✅ 2. Клиентские tools (Generative UI)
- ✅ `askForConfirmation` - запрос подтверждения у пользователя
- ✅ `getLocation` - получение локации (автоматически выполняется)
- ✅ `requestDangerousActionConfirmation` - подтверждение опасных действий

#### ✅ 3. Подтверждение опасных действий
- ✅ Двухэтапный процесс: запрос подтверждения → выполнение действия
- ✅ UI компоненты для подтверждения (карточки с кнопками Да/Нет)
- ✅ Поддержка действий: `deleteThread`, `deleteMessage`, `updateMessage`, `updateXlsxCell`

#### ✅ 4. Таблица сообщений треда
- ✅ `getThreadMessagesTable` - server tool для получения сообщений треда в виде таблицы
- ✅ `openTable` - client tool для открытия UI таблицы
- ✅ Визуальное отображение таблицы сообщений с колонками: ID, Роль, Содержание, Дата
- ✅ Редактирование сообщений через inline edit в таблице
- ✅ Удаление сообщений через кнопку в таблице
- ✅ Подтверждение опасных действий (редактирование/удаление) через 2-этапный процесс
- ✅ Автоматическое обновление таблицы после выполнения операций

#### ✅ 5. Работа с XLSX таблицей
- ✅ Tools для работы с таблицей:
  - `getRange` - чтение диапазона ячеек
  - `updateCell` - запись в ячейку (с подтверждением)
  - `explainFormula` - объяснение формул
  - `getSheets` - список листов
- ✅ Визуальное отображение таблицы в чате (мини-превью)
- ✅ Модальное окно с полной таблицей
- ✅ Выделение ячеек мышкой в модалке
- ✅ Меншоны диапазонов (например, `@Sheet1!A1:B3`)
- ✅ Вставка меншонов в поле ввода чата

## 📁 Структура проекта

Проект организован по принципу разделения слоёв (API / UI / DB):

```
chatgpt-lite/
├── app/                          # Next.js App Router
│   ├── api/                      # API слой (Backend)
│   │   ├── chat/route.ts         # POST /api/chat - streaming чат
│   │   ├── threads/              # API для тредов
│   │   └── messages/             # API для сообщений
│   ├── threads/                  # UI слой (Frontend)
│   │   ├── [id]/
│   │   │   ├── page.tsx          # Server Component страницы треда
│   │   │   ├── ChatClient.tsx     # Client Component чата (useChat, Generative UI)
│   │   │   ├── TableMessage.tsx  # Компонент отображения XLSX таблицы
│   │   │   ├── MessagesTable.tsx  # Компонент таблицы сообщений треда
│   │   │   └── EditMessageModal.tsx
│   │   └── page.tsx              # Список тредов
│   └── layout.tsx
├── lib/                          # Бизнес-логика
│   ├── db/                       # DB слой
│   │   ├── client.ts            # Инициализация Bun SQLite
│   │   └── chat-store.ts        # CRUD операции для threads/messages
│   ├── tools/                    # AI SDK Tools
│   │   ├── chat-tools.ts        # Клиентские tools (Generative UI)
│   │   │                         # - askForConfirmation
│   │   │                         # - getLocation
│   │   │                         # - requestDangerousActionConfirmation
│   │   │                         # - openTable
│   │   ├── server-tools.ts      # Серверные tools (опасные действия)
│   │   │                         # - getThreadMessagesTable
│   │   │                         # - performDangerousAction
│   │   └── xlsx-tools.ts        # Tools для работы с XLSX
│   └── xlsx/
│       └── table-manager.ts     # Управление XLSX файлом
├── data/
│   ├── chat.db                  # SQLite база данных (создаётся автоматически)
│   └── example.xlsx             # Пример таблицы
└── scripts/                     # Утилиты
    ├── test-chat.ts             # Тестирование API
    └── test-openai-direct.ts    # Прямое тестирование OpenAI
```

## 🧪 Тестирование по критериям ТЗ

### Критерий 1: Чат с тредами

**Тест 1.1: Создание треда**
```
1. Откройте http://localhost:3000/threads
2. Введите название треда в поле "Название треда"
3. Нажмите "Создать"
4. ✅ Тред должен появиться в сайдбаре
```

**Тест 1.2: Отправка сообщения**
```
1. Выберите тред из списка
2. Введите сообщение: "Привет! Что умеешь?"
3. Нажмите Enter или кнопку отправки
4. ✅ Ответ должен стримиться в реальном времени
5. ✅ Сообщение должно сохраниться в БД
```

**Тест 1.3: Переключение между тредами**
```
1. Создайте несколько тредов
2. Отправьте сообщения в разных тредах
3. Переключайтесь между тредами
4. ✅ История сообщений должна загружаться из БД
```

### Критерий 2: Клиентские tools

**Тест 2.1: askForConfirmation**
```
1. Откройте чат
2. Отправьте: "Спроси у меня подтверждение на действие X"
3. ✅ Должна появиться карточка с вопросом и кнопками Да/Нет
```

**Тест 2.2: getLocation**
```
1. Откройте чат
2. Отправьте: "Где я нахожусь?"
```

**Тест 3.1: Удаление треда**

```
1. Откройте чат с сообщениями
2. Правый клик на сообщении пользователя → "Удалить"
3. ✅ Должна появиться карточка подтверждения
4. Нажмите "Да"
5. ✅ Сообщение должно удалиться
```

**Тест 3.3: Редактирование сообщения**
```

2. Правый клик на сообщении → "Редактировать"
3. Введите новый текст
4. Нажмите "Сохранить"
5. ✅ Должна появиться карточка подтверждения
6. Нажмите "Да"
7. ✅ Сообщение должно обновиться
```

### Критерий 4: Таблица сообщений треда

**Тест 4.1: Показ таблицы сообщений**
```
1. Откройте чат с сообщениями
2. Отправьте: "Покажи таблицу сообщений"
3. ✅ Должен вызваться tool getThreadMessagesTable
4. ✅ Затем должен вызваться tool openTable
5. ✅ В чате должна появиться таблица с сообщениями
```

**Тест 4.2: Редактирование сообщения через таблицу**

```
4. Нажмите "✓" (Save)
5. ✅ Должна появиться карточка подтверждения
6. Нажмите "Да"
7. ✅ Сообщение должно обновиться в таблице и в чате
8. ✅ Таблица должна обновиться без перезагрузки страницы
```

**Тест 4.3: Удаление сообщения через таблицу**
```
1. Откройте таблицу сообщений
2. Нажмите кнопку "🗑️" напротив сообщения
3. ✅ Должна появиться карточка подтверждения
4. Нажмите "Да"
5. ✅ Сообщение должно удалиться из таблицы и из чата
6. ✅ Таблица должна обновиться без перезагрузки страницы
```

**Тест 4.4: Отказ в подтверждении**
```

5. ✅ Сообщение НЕ должно измениться
```

## 🔧 API Endpoints

### `POST /api/chat`
Отправка сообщения в чат (streaming)

**Body:**
```json
{
  "id": "thread-id",
  "messages": [...]
}
```

### `GET /api/threads`
Получить список всех тредов

### `POST /api/threads`
Создать новый тред

**Body:**
```json
{
  "title": "Название треда"
}
```

### `GET /api/threads/[id]`
Получить информацию о треде

### `DELETE /api/threads/[id]`
Удалить тред

### `GET /api/threads/[id]/messages`
Получить все сообщения треда

### `GET /api/messages/[id]`
Получить конкретное сообщение

### `GET /api/db-check`
Проверка состояния БД

## 🗄 База данных

### Таблица `threads`
- `id` (TEXT PRIMARY KEY)
- `title` (TEXT NOT NULL)
- `created_at` (INTEGER NOT NULL)

### Таблица `messages`
- `id` (TEXT PRIMARY KEY)
- `thread_id` (TEXT NOT NULL, FOREIGN KEY)
- `role` (TEXT NOT NULL, CHECK: 'user' | 'assistant')
- `content` (TEXT NOT NULL)
- `created_at` (INTEGER NOT NULL)

База данных создаётся автоматически при первом запуске в `data/chat.db`.
