# ChatGPT-lite

Упрощённый аналог интерфейса ChatGPT с тредами, хранением сообщений в базе и **генеративным UI** на основе Vercel AI SDK.

---

## 🚀 Пошаговая инструкция по запуску проекта

### Шаг 1: Проверка установки Bun

Откройте терминал (PowerShell на Windows, Terminal на macOS/Linux) и выполните:

```bash
bun --version
```

**Если команда не найдена** — перейдите к [Шагу 2: Установка Bun](#шаг-2-установка-bun)

**Если версия 1.3 или выше** — переходите к [Шагу 3: Подготовка проекта](#шаг-3-подготовка-проекта)

---

### Шаг 2: Установка Bun

#### Windows (PowerShell):
```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```

После установки:
- Закройте и откройте терминал заново
- Или выполните: `refreshenv` (если установлен через Chocolatey)

```bash
curl -fsSL https://bun.sh/install | bash
```

После установки:
- Закройте и откройте терминал заново
- Или выполните: `source ~/.bashrc` (или `source ~/.zshrc`)

```bash
bun --version
```
Должна быть версия **1.3+**

### Шаг 4: Установка зависимостей

Выполните команду:

```bash
bun install
```

**Что происходит:**
- Устанавливаются все зависимости из `package.json`
- Создаётся папка `node_modules/`
- Создаётся файл `bun.lockb`

**Ожидаемое время:** 1-3 минуты

**Если возникли ошибки:**
- Убедитесь, что Bun установлен: `bun --version`
- Удалите `node_modules` и `bun.lockb` (если есть) и повторите установку

### Шаг 5: Настройка API ключа OpenAI

1. **Получите API ключ OpenAI**:
   - Зайдите на https://platform.openai.com/api-keys
   - Войдите в аккаунт (или создайте новый)
   - Нажмите "Create new secret key"
   - Скопируйте ключ (он начинается с `sk-proj-` или `sk-`)

2. **Создайте файл `.env.local`** в корне проекта:

   **Вариант 1 (через терминал):**
   ```bash
   # Windows (PowerShell)
   echo "OPENAI_API_KEY=ваш_ключ_здесь" > .env.local
   
   # macOS/Linux
   echo "OPENAI_API_KEY=ваш_ключ_здесь" > .env.local
   ```

   **Вариант 2 (вручную):**
   - Создайте файл `.env.local` в корне проекта (там же, где `package.json`)
   - Откройте файл в текстовом редакторе
   - Добавьте строку:
     ```env
     OPENAI_API_KEY=sk-proj-ваш_ключ_здесь
     ```
   - Сохраните файл

3. **Проверьте файл**:
   ```bash
   # Windows
   type .env.local
   
   # macOS/Linux
   cat .env.local
   ```

   Должна быть строка: `OPENAI_API_KEY=sk-proj-...`

   **⚠️ Важно:** 
   - Не добавляйте пробелы вокруг `=`
   - Не используйте кавычки вокруг ключа
   - Файл `.env.local` уже добавлен в `.gitignore` и не попадёт в Git

### Шаг 7: Запуск проекта

#### Вариант 1: С автозапуском браузера (рекомендуется)

```bash
bun run dev
```

**Что происходит:**
- Запускается Next.js dev сервер
- Через 3 секунды автоматически откроется браузер на http://localhost:3000
- В терминале будут видны логи сервера

#### Вариант 2: Без автозапуска браузера

```bash
bun run dev:simple
```

**Что происходит:**
- Запускается Next.js dev сервер
- Браузер не открывается автоматически
- Откройте вручную: http://localhost:3000

1. **Откройте браузер**: http://localhost:3000

2. **Должна открыться главная страница** с приветствием

## 📋 Реализованные функции

### ✅ 1. Чат с тредами

- ✅ Список тредов в сайдбаре слева
- ✅ Создание нового треда
- ✅ Переключение между тредами
- ✅ Загрузка истории сообщений из БД при переключении
- ✅ Streaming ответы от модели (SSE)
- ✅ Сохранение всех сообщений (user и assistant) в SQLite
- ✅ Персистентность: все сообщения сохраняются в базе данных

### ✅ 2. Клиентские tools (Generative UI)

- ✅ `askForConfirmation` - запрос подтверждения у пользователя
- ✅ `getLocation` - получение локации (автоматически выполняется)
- ✅ `requestDangerousActionConfirmation` - подтверждение опасных действий
- ✅ `openTable` - открытие таблицы данных в UI (для отображения структурированных данных)

### ✅ 3. Подтверждение опасных действий

- ✅ Двухэтапный процесс: запрос подтверждения → выполнение действия
- ✅ UI компоненты для подтверждения (карточки с кнопками Да/Нет)
- ✅ Поддержка действий:
  - `deleteThread` - удаление треда (напрямую через UI в сайдбаре, без участия модели)
  - `updateXlsxCell` - обновление ячейки XLSX (через модель с подтверждением)
  
**Примечание:** Удаление и редактирование сообщений через контекстное меню в чате (правый клик по сообщению пользователя) реализовано визуально, но функция не полностью реализована (см. раздел "Частично реализованные функции").

### ✅ 4. Таблица сообщений треда

- ✅ `getThreadMessagesTable` - server tool для получения сообщений треда в виде таблицы
- ✅ `openTable` - client tool для открытия UI таблицы
- ✅ Визуальное отображение таблицы сообщений с колонками: ID, Роль, Содержание, Дата
- ✅ Редактирование сообщений прямо в таблице (inline edit): ячейка с содержимым превращается в поле редактирования при нажатии кнопки "✏️"
- ✅ Подтверждение опасных действий (редактирование) через 2-этапный процесс
- ✅ Автоматическое обновление таблицы после выполнения операций

### ✅ 5. Работа с XLSX таблицей

- ✅ **Tools для работы с таблицей:**
  - `getRange` - чтение диапазона ячеек
  - `updateCell` - запись в ячейку (с подтверждением)
  - `explainFormula` - объяснение формул
  - `getSheets` - список листов
  - `getUsedRange` - получение используемого диапазона листа (от первой до последней заполненной ячейки)
  - `logInvites` - отправка email приглашений (симуляция, логирование)
  
- ✅ **Визуальное отображение:**
  - Мини-превью таблицы в чате
  - Модальное окно с полной таблицей
  - Выделение ячеек мышкой в модалке
  - Редактирование ячеек:
    - Тройной клик левой кнопкой мыши по ячейке открывает редактирование прямо в таблице
    - Через запрос к ассистенту в сообщении (например, "Измени ячейку Sheet1!C2 на 5000")
  - Переключатель режимов отображения: кнопка "🔢 Формулы" / "📊 Значения" в модальном окне таблицы
    - По умолчанию показываются вычисленные значения ячеек
    - При нажатии "🔢 Формулы" отображаются формулы Excel (с символом `=`)
    - При нажатии "📊 Значения" возвращается к отображению вычисленных значений
    - Переключение работает в реальном времени для всех ячеек таблицы
    - **Примеры использования:**
      - Выбор ячейки с формулой: включите режим "🔢 Формулы", найдите нужную ячейку, увидите формулу (например, `=SUM(A1:A5)`)
      - Замена формулы: включите режим "🔢 Формулы", выберите ячейку, тройной клик левой кнопкой мыши для редактирования формулы
      - Проверка формул: переключитесь в режим формул, чтобы увидеть все формулы в таблице и проверить их корректность
  
- ✅ **Меншоны диапазонов:**
  - Формат: `@Sheet1!A1:B3` (например)
  - Создание меншона: нажмите на одну ячейку левой кнопкой мыши и растягивайте (drag) для выделения диапазона
  - Вставка меншонов в поле ввода чата (после выделения диапазона в модалке нажмите кнопку "Вставить меншон")
  - Интеграция с агентом: понимание меншонов и использование соответствующих tools
  - Отправка приглашений: агент может взять email из диапазона (например, `@Sheet1!B2:B5`) и отправить приглашения через `logInvites`
  
- ✅ **Формулы Excel:**
  - Поддержка формул: SUM, AVERAGE, MIN, MAX, COUNT, арифметические операции
  - Автоматический пересчёт формул при изменении ячеек

**Пример работы с приглашениями:**
1. В таблице должны быть email адреса (например, в колонке B, строки 2-5)
2. Выделите диапазон с email: нажмите на ячейку B2 левой кнопкой мыши и растягивайте (drag) до B5 в модальном окне таблицы
3. Нажмите "Вставить меншон" - появится `@Sheet1!B2:B5`
4. Отправьте команду: "Отправь приглашения на @Sheet1!B2:B5"
5. ✅ Агент извлечёт email из диапазона и отправит приглашения через `logInvites`

## ⚠️ Частично реализованные функции

### 🔶 Удаление и редактирование сообщений

**Статус:** Реализовано во фронтенде, но не полностью интегрировано с backend.

**Что работает:**
- ✅ Контекстное меню на сообщениях пользователя (правый клик)
- ✅ Кнопки "Изменить" и "Удалить" в контекстном меню
- ✅ Таблица сообщений треда с кнопками "✏️" и "🗑️" для редактирования/удаления
- ✅ Модальное окно для редактирования сообщения (контекстное меню)
- ✅ Inline редактирование в таблице сообщений
- ✅ Отправка команды модели для удаления/редактирования

**Что не реализовано:**
- ❌ Прямое удаление/редактирование через API без участия модели
- ❌ Мгновенное обновление UI после удаления/редактирования (требуется ответ модели)

**Как это работает сейчас:**
1. Пользователь нажимает "Удалить" или "Изменить" (через контекстное меню или кнопки в таблице)
2. Отправляется текстовая команда модели (например, `"Удалить сообщение [id]"` или `"Измени сообщение [id] на: новый текст"`)
3. Модель вызывает `requestDangerousActionConfirmation` → `performDangerousAction`
4. Действие выполняется через backend API

**В отличие от остального функционала:**
- Удаление треда работает полностью (напрямую через UI в сайдбаре, с подтверждением и редиректом, без участия модели)
- Обновление XLSX ячеек работает полностью (через модель с подтверждением и обновлением таблицы)

## 🔧 API Endpoints

### `POST /api/chat`
Отправка сообщения в чат (streaming)

**Body:**
```json
{
  "id": "thread-id",
  "messages": [...]
}
```

### `GET /api/threads`
Получить список всех тредов

### `POST /api/threads`
Создать новый тред

**Body:**
```json
{
  "title": "Название треда"
}
```

### `DELETE /api/threads/[id]`
Удалить тред

### `GET /api/threads/[id]/messages`
Получить все сообщения треда

### `GET /api/db-check`
Проверка базы данных

**Response:**
```json
{
  "ok": true,
  "threads": 5,
  "messages": 42
}
```

### `GET /api/xlsx/range`
Получить диапазон ячеек из XLSX

**Query params:**
- `sheet` - название листа
- `from` - начальная ячейка (например, A1)
- `to` - конечная ячейка (например, D6)

### `POST /api/xlsx/get-range`
Получить диапазон ячеек из XLSX (альтернативный endpoint)

**Body:**
```json
{
  "sheet": "Sheet1",
  "from": "A1",
  "to": "D6"
}
```

### `POST /api/xlsx/update-cell`
Обновить ячейку XLSX (после подтверждения пользователя)

**Body:**
```json
{
  "sheet": "Sheet1",
  "cell": "C2",
  "value": 5000
}
```

### `POST /api/xlsx/perform`
Выполнить действие с XLSX (обновление ячейки)

**Body:**
```json
{
  "action": "updateXlsxCell",
  "targetId": "C2",
  "newContent": "Sheet1",
  "xlsxValue": "5000"
}
```

## ⚠️ Ограничения и известные проблемы

### Ограничения:
- ❌ E2E тесты на Playwright (не реализовано)
- ⚠️ XLSX файл захардкожен (`data/example.xlsx`)
- ⚠️ Поддержка только одного XLSX файла
- ⚠️ Нет поддержки создания новых листов в XLSX
- ⚠️ Удаление/редактирование сообщений через контекстное меню работает через модель (см. раздел "Частично реализованные функции")

### Известные проблемы:
- При удалении/редактировании сообщения через контекстное меню требуется ответ модели для обновления UI
- Некоторые сложные Excel формулы могут не поддерживаться (поддерживаются: SUM, AVERAGE, MIN, MAX, COUNT, арифметические операции)
