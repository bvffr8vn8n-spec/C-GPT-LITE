# ChatGPT-lite

Упрощённый аналог интерфейса ChatGPT с тредами, хранением сообщений в базе и **генеративным UI** на основе Vercel AI SDK.

---

## 🚀 Быстрый старт

### Требования

- **Bun 1.3+** (для встроенной SQLite)
- **OpenAI API ключ** (получить можно на https://platform.openai.com/api-keys)

### Установка

1. **Клонируйте репозиторий** (или распакуйте архив):
   ```bash
   cd chatgpt-lite
   ```

2. **Установите зависимости**:
   ```bash
   bun install
   ```

3. **Создайте файл `.env.local`** в корне проекта:
   ```bash
   echo "OPENAI_API_KEY=your_key_here" > .env.local
   ```
   
   Или создайте файл вручную и добавьте:
   ```env
   OPENAI_API_KEY=sk-proj-ваш_ключ_здесь
   ```

4. **Запустите проект**:
   ```bash
   bun run dev
   ```

5. **Откройте браузер**: http://localhost:3000

   Браузер откроется автоматически через 3 секунды (если используете `bun run dev`).

## ⚙️ Конфигурация

### Переменные окружения

Создайте файл `.env.local` в корне проекта:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

**Важно:**

```bash

```

## 📋 Реализованные функции

### ✅ 1. Чат с тредами

- ✅ Список тредов в сайдбаре слева
- ✅ Создание нового треда
- ✅ Переключение между тредами
- ✅ Загрузка истории сообщений из БД при переключении
- ✅ Streaming ответы от модели (SSE)
- ✅ Сохранение всех сообщений (user и assistant) в SQLite
- ✅ Персистентность: все сообщения сохраняются в базе данных

### ✅ 2. Клиентские tools (Generative UI)

- ✅ `askForConfirmation` - запрос подтверждения у пользователя
- ✅ `getLocation` - получение локации (автоматически выполняется)
- ✅ `requestDangerousActionConfirmation` - подтверждение опасных действий
- ✅ `openTable` - открытие таблицы сообщений в UI

### ✅ 3. Подтверждение опасных действий

- ✅ Двухэтапный процесс: запрос подтверждения → выполнение действия
- ✅ UI компоненты для подтверждения (карточки с кнопками Да/Нет)
- ✅ Поддержка действий:
  - `deleteThread` - удаление треда
  - `deleteMessage` - удаление сообщения (через модель)
  - `updateMessage` - обновление сообщения (через модель)
  - `updateXlsxCell` - обновление ячейки XLSX

### ✅ 4. Таблица сообщений треда

- ✅ `getThreadMessagesTable` - server tool для получения сообщений треда в виде таблицы
- ✅ `openTable` - client tool для открытия UI таблицы
- ✅ Визуальное отображение таблицы сообщений с колонками: ID, Роль, Содержание, Дата
- ✅ Редактирование сообщений через inline edit в таблице
- ✅ Удаление сообщений через кнопку в таблице
- ✅ Подтверждение опасных действий (редактирование/удаление) через 2-этапный процесс
- ✅ Автоматическое обновление таблицы после выполнения операций

### ✅ 5. Работа с XLSX таблицей

- ✅ Tools для работы с таблицей:
  - `getRange` - чтение диапазона ячеек
  - `updateCell` - запись в ячейку (с подтверждением)
  - `explainFormula` - объяснение формул
  - `getSheets` - список листов
- ✅ Визуальное отображение таблицы в чате (мини-превью)
- ✅ Модальное окно с полной таблицей
- ✅ Выделение ячеек мышкой в модалке
- ✅ Меншоны диапазонов (например, `@Sheet1!A1:B3`)
- ✅ Вставка меншонов в поле ввода чата
- ✅ Интеграция с агентом: понимание меншонов и использование соответствующих tools
- ✅ Поддержка формул Excel (SUM, AVERAGE, MIN, MAX, арифметические операции)
- ✅ Автоматический пересчёт формул при изменении ячеек

## ⚠️ Частично реализованные функции

### 🔶 Удаление и редактирование сообщений через контекстное меню

**Статус:** Реализовано во фронтенде, но не полностью интегрировано с backend.

**Что работает:**
- ✅ Контекстное меню на сообщениях пользователя (правый клик)
- ✅ Кнопки "Изменить" и "Удалить" в меню
- ✅ Модальное окно для редактирования сообщения
- ✅ Отправка команды модели для удаления/редактирования

**Что не реализовано:**
- ❌ Прямое удаление/редактирование через API без участия модели
- ❌ Мгновенное обновление UI после удаления/редактирования (требуется ответ модели)

**Как это работает сейчас:**
1. Пользователь нажимает "Удалить" или "Изменить" в контекстном меню
2. Отправляется текстовая команда модели (например, `"Удалить сообщение [id]"`)
3. Модель вызывает `requestDangerousActionConfirmation` → `performDangerousAction`
4. Действие выполняется через backend API

**В отличие от остального функционала:**
- Удаление/редактирование через таблицу сообщений работает полностью (с подтверждением и мгновенным обновлением)
- Удаление треда работает полностью (с подтверждением и редиректом)
- Обновление XLSX ячеек работает полностью (с подтверждением и обновлением таблицы)

## 🗄 База данных

### Таблица `threads`
- `id` (TEXT PRIMARY KEY)
- `title` (TEXT NOT NULL)
- `created_at` (INTEGER NOT NULL)

### Таблица `messages`
- `id` (TEXT PRIMARY KEY)
- `thread_id` (TEXT NOT NULL, FOREIGN KEY)
- `role` (TEXT NOT NULL, CHECK: 'user' | 'assistant')
- `content` (TEXT NOT NULL) - JSON строка с parts для assistant сообщений
- `created_at` (INTEGER NOT NULL)

База данных создаётся автоматически при первом запуске в `data/chat.db`.

## 📝 Примеры использования

### Работа с чатом:
- `"Привет! Что умеешь?"` - обычный запрос
- `"Где я нахожусь?"` - автоматически вызовет `getLocation`
- `"Спроси у меня подтверждение на действие X"` - вызовет `askForConfirmation`

### Работа с таблицей сообщений:
- `"Покажи таблицу сообщений"` - откроет таблицу с сообщениями треда
- `"Покажи сообщения в виде таблицы"` - альтернативная команда

### Работа с XLSX таблицей:
- `"Покажи таблицу из Sheet1"` - покажет весь лист
- `"Прочитай диапазон Sheet1!A1:C5"` - покажет конкретный диапазон
- `"Измени ячейку Sheet1!C2 на 5000"` - обновит ячейку (с подтверждением)
- `"Объясни формулу в Sheet1!D6"` - объяснит формулу
- `"Какие листы есть в файле?"` - покажет список листов

### Опасные действия:
- `"Удали этот тред"` - удалит текущий тред (с подтверждением)
- `"Удали сообщение [id]"` - удалит сообщение (с подтверждением)

### Меншоны диапазонов:
- Выделите диапазон в модалке таблицы → нажмите "Вставить меншон"
- В поле ввода появится `@Sheet1!A1:B3`
- Используйте в запросах: `"Объясни формулу в @Sheet1!D6"`

## 🔧 API Endpoints

### `POST /api/chat`
Отправка сообщения в чат (streaming)

**Body:**
```json
{
  "id": "thread-id",
  "messages": [...]
}
```

### `GET /api/threads`
Получить список всех тредов

### `POST /api/threads`
Создать новый тред

**Body:**
```json
{
  "title": "Название треда"
}
```

### `DELETE /api/threads/[id]`
Удалить тред

### `GET /api/threads/[id]/messages`
Получить все сообщения треда

### `GET /api/xlsx/range`
Получить диапазон ячеек из XLSX

**Query params:**
- `sheet` - название листа
- `from` - начальная ячейка (например, A1)
- `to` - конечная ячейка (например, D6)

### `POST /api/xlsx/perform`
Выполнить действие с XLSX (обновление ячейки)

**Body:**
```json
{
  "action": "updateXlsxCell",
  "targetId": "C2",
  "newContent": "Sheet1",
  "xlsxValue": "5000"
}
```

## ⚠️ Ограничения и известные проблемы

### Ограничения:
- ❌ E2E тесты на Playwright (не реализовано)
- ⚠️ XLSX файл захардкожен (`data/example.xlsx`)
- ⚠️ Поддержка только одного XLSX файла
- ⚠️ Нет поддержки создания новых листов в XLSX
- ⚠️ Удаление/редактирование сообщений через контекстное меню работает через модель (см. раздел "Частично реализованные функции")

### Известные проблемы:
- При удалении/редактировании сообщения через контекстное меню требуется ответ модели для обновления UI
- Некоторые сложные Excel формулы могут не поддерживаться (поддерживаются: SUM, AVERAGE, MIN, MAX, COUNT, арифметические операции)
