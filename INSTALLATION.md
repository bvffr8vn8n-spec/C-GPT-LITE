# Пошаговая инструкция по установке и запуску проекта

## Шаг 1: Установка Bun

### Windows:
1. Откройте PowerShell или Command Prompt
2. Выполните команду:
```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```
3. Перезапустите терминал или выполните:
```powershell
refreshenv
```

### macOS/Linux:
```bash
curl -fsSL https://bun.sh/install | bash
```

### Проверка установки:
```bash
bun --version
```
Должна быть версия **1.3+**

---

## Шаг 2: Клонирование проекта

### Если проект в Git репозитории:
```bash
git clone <url-репозитория>
cd chatgpt-lite
```

### Если проект на флешке/в архиве:
1. Распакуйте архив или скопируйте папку проекта
2. Откройте терминал в папке проекта:
```bash
cd путь/к/папке/chatgpt-lite
```

---

## Шаг 3: Установка зависимостей

```bash
bun install
```

Это установит все необходимые пакеты из `package.json`.

**Ожидаемое время:** 1-3 минуты

---

## Шаг 4: Настройка окружения

1. Создайте файл `.env.local` в корне проекта (там же, где `package.json`)

2. Откройте файл в текстовом редакторе и добавьте:

```env
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4o-mini
DB_PATH=./data/app.db
```

3. **Важно:** Замените `your_openai_api_key_here` на ваш реальный API ключ OpenAI

### Как получить API ключ OpenAI:
1. Зайдите на https://platform.openai.com/api-keys
2. Войдите в аккаунт (или создайте новый)
3. Нажмите "Create new secret key"
4. Скопируйте ключ и вставьте в `.env.local`

**Пример:**
```env
OPENAI_API_KEY=sk-proj-abc123xyz789...
```

## Шаг 5: Инициализация базы данных

База данных создастся **автоматически** при первом запуске, но можно проверить:

```bash
# Проверка структуры проекта
ls -la data/  # или dir data в Windows
```

Если папки `data` нет - она создастся автоматически.

---

## Шаг 6: Создание примера XLSX файла

XLSX файл создастся автоматически, но можно создать вручную:

```bash
bun run scripts/create-example-xlsx.ts
```

Проверка:
```bash
ls data/example.xlsx  # или dir data\example.xlsx в Windows
```

---

## Шаг 7: Запуск проекта

### Режим разработки (с автозапуском браузера):
```bash
bun run dev
```

Браузер откроется автоматически через 3 секунды на `http://localhost:3000`

### Режим разработки (без автозапуска браузера):
```bash
bun run dev:simple
```

Затем откройте вручную: http://localhost:3000

---

## Шаг 8: Проверка работы

1. **Откройте браузер:** http://localhost:3000
2. **Должна открыться главная страница** с приветствием
3. **Нажмите "Открыть чаты"** или перейдите на http://localhost:3000/threads
4. **Создайте новый чат:**
   - Введите название в поле "Название треда"
   - Нажмите "Создать"
5. **Отправьте тестовое сообщение:**
   - Введите: "Привет!"
   - Нажмите Enter или кнопку отправки
6. **Проверка:** Должен прийти ответ от ассистента

## Возможные проблемы и решения

### Проблема 1: "bun: command not found"
**Решение:** 
- Убедитесь, что Bun установлен: `bun --version`
- Перезапустите терминал
- Проверьте PATH переменную

### Проблема 2: "Missing OPENAI_API_KEY"
**Решение:**
- Проверьте, что файл `.env.local` существует
- Убедитесь, что ключ указан правильно (без пробелов, кавычек)
- Перезапустите dev сервер после изменения `.env.local`

### Проблема 3: "Port 3000 is already in use"
**Решение:**
- Закройте другое приложение на порту 3000
- Или измените порт в `next.config.ts`

### Проблема 4: "Failed to read range" (XLSX)
**Решение:**
- Убедитесь, что файл `data/example.xlsx` существует
- Пересоздайте файл: `bun run scripts/create-example-xlsx.ts`

### Проблема 5: Ошибки при установке зависимостей
**Решение:**
- Удалите `node_modules` и `bun.lockb`
- Выполните: `bun install` заново

## Структура файлов после установки

```
chatgpt-lite/
├── .env.local          # Ваш файл с API ключом (создайте вручную)
├── data/
│   ├── app.db          # База данных (создастся автоматически)
│   └── example.xlsx    # XLSX таблица (создастся автоматически)
├── node_modules/       # Зависимости (после bun install)
├── app/                # Код приложения
├── lib/                # Библиотеки
└── package.json        # Конфигурация проекта
```

## Команды для работы

```bash
# Разработка
bun run dev              # Запуск с автозапуском браузера
bun run dev:simple       # Запуск без автозапуска

# Production
bun run build            # Сборка проекта
bun run start            # Запуск production версии

# Утилиты
bun run scripts/check-db.ts              # Проверка БД
bun run scripts/create-example-xlsx.ts   # Создание XLSX файла
```

## Быстрый старт (краткая версия)

```bash
# 1. Установить Bun
powershell -c "irm bun.sh/install.ps1 | iex"  # Windows

# 2. Перейти в папку проекта
cd chatgpt-lite

# 3. Установить зависимости
bun install

# 4. Создать .env.local с API ключом
echo "OPENAI_API_KEY=ваш_ключ" > .env.local

# 5. Запустить
bun run dev
```
