## ✅ ТРЕБОВАНИЕ 1.2: Область чата

### Требование
- Реализовать чат через **`useChat`** из AI SDK UI.
- При отправке сообщения:
  - запрос уходит на `/api/chat`;
  - ответ от модели стримится и отображается;
  - сообщения (user/assistant) сохраняются в базе и привязаны к треду.
- При переключении треда:
  - происходит загрузка истории сообщений из базы;
  - `useChat` инициализируется текущими сообщениями.

### Проверка

#### ✅ 1.2.1: Использование useChat из AI SDK UI
- ✅ **Импорт:** `import { useChat } from "@ai-sdk/react"`
- ✅ **Инициализация:** `useChat` настроен с `messages: initialMessages`, `transport`, `onError`
- ✅ **Функции:** Используются `sendMessage`, `addToolResult`, `setMessages`, `messages`, `status`, `error`

**Файлы:**
- `app/threads/[id]/ChatClient.tsx` (строки 6, 516-526) - использование useChat

**Статус:** ✅ **ВЫПОЛНЕНО**

#### ✅ 1.2.2: Запрос на `/api/chat` при отправке
- ✅ **Transport:** Настроен `DefaultChatTransport` с `api: "/api/chat"`
- ✅ **Body:** Передаётся `threadId` и `spreadsheetContext` в body запроса
- ✅ **Отправка:** `sendMessage` отправляет сообщение через transport

**Файлы:**
- `app/threads/[id]/ChatClient.tsx` (строки 519-526) - настройка transport
- `app/api/chat/route.ts` (строка 53) - POST endpoint

**Статус:** ✅ **ВЫПОЛНЕНО**

#### ✅ 1.2.3: Стриминг ответа от модели
- ✅ **Streaming:** Используется `streamText` из AI SDK
- ✅ **Response:** Возвращается `result.toUIMessageStreamResponse()` для SSE стриминга
- ✅ **Отображение:** Сообщения обновляются в реальном времени через `useChat`

**Файлы:**
- `app/api/chat/route.ts` (строки 184-193) - streamText и toUIMessageStreamResponse
- `app/threads/[id]/ChatClient.tsx` - автоматическое обновление через useChat

**Статус:** ✅ **ВЫПОЛНЕНО**

#### ✅ 1.2.4: Сохранение сообщений в БД
- ✅ **User сообщения:** Сохраняются в `onFinish` callback перед отправкой запроса
- ✅ **Assistant сообщения:** Сохраняются в `onFinish` callback после получения ответа
- ✅ **Привязка к треду:** Все сообщения сохраняются с `thread_id`

**Файлы:**
- `app/api/chat/route.ts` (строки 121-125) - сохранение user сообщения
- `app/api/chat/route.ts` (строки 210-217) - сохранение assistant сообщения в onFinish
- `lib/db/chat-store.ts` (строки 24-38) - функция `appendDbMessage`

**Статус:** ✅ **ВЫПОЛНЕНО**

#### ✅ 1.2.5: Загрузка истории при переключении треда
- ✅ **Загрузка:** В `page.tsx` вызывается `loadMessages(threadId)` из БД
- ✅ **Преобразование:** Сообщения конвертируются в `UIMessage[]` через `convertToUIMessages`
- ✅ **Передача:** `initialMessages` передаются в `ChatClient` как prop

**Файлы:**
- `app/threads/[id]/page.tsx` (строки 12-14, 17-37, 48-49) - загрузка и преобразование
- `app/threads/[id]/ChatClient.tsx` (строка 518) - инициализация useChat с initialMessages

**Статус:** ✅ **ВЫПОЛНЕНО**
