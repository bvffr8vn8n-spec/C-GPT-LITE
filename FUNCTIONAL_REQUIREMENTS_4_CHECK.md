## ✅ ТРЕБОВАНИЕ 4.2: Tools для работы с таблицей

### Требование
- Реализовать минимум 2–3 tools:
  1. **Чтение диапазона ячеек** (например, `getRange(sheet, from, to)`).
  2. **Запись в ячейку/диапазон** (например, `updateCell(sheet, cell, value)`).
  3. Опционально — tool для вычисления/объяснения формулы в ячейке.
- Все **записывающие действия** должны проходить через механику **подтверждения**, описанную выше:
  - сначала запрос через tool → UI с «Да/Нет» → только после «Да» реально меняем таблицу и сохраняем.

### Проверка

#### ✅ 4.2.1: Tool для чтения диапазона ячеек
- ✅ **getRange:** Реализован в `xlsx-tools.ts`
  - Input: `sheet` (опционально, дефолт "Sheet1"), `from` (опционально, дефолт "A1"), `to` (опционально, дефолт "H30")
  - Output: `sheet`, `range`, `data` (2D массив), `headers` (опционально)
  - Execute: Читает диапазон через `tableManager.getRange()`

**Файлы:**
- `lib/tools/xlsx-tools.ts` (строки 9-37) - определение getRange

## ✅ ТРЕБОВАНИЕ 4.5: Меншоны диапазонов

### Требование
- После выделения ячеек в модалке:
  - пользователь может «сохранить» выделение как ссылку/упоминание диапазона (например, `@Sheet1!A1:B3`);
  - это упоминание вставляется в поле ввода чата (или непосредственно в сообщение) так, чтобы агент мог использовать этот диапазон:
    - пример: *«Объясни формулу, по которой посчиталась ячейка @Sheet1!D4»*;
    - пример: *«Возьми email из диапазона @Sheet1!B2:B5 и отправь им приглашения»*.

### Проверка
- ✅ **Формирование меншона:** Функция `getSelectedRange()` формирует меншон в формате `@Sheet1!A1:B3`

- ✅ **Callback onRangeSelect:** Модалка вызывает `onRangeSelect(range)` при нажатии кнопки
- ⚠️ **Вставка в поле ввода:** Требуется проверка интеграции с `NewMessageForm`

**Файлы:**

## 📝 Дополнительные детали реализации

### Tools для работы с таблицей
- **getRange:** Читает диапазон ячеек, возвращает 2D массив данных
- **updateCell:** Обновляет значение ячейки (требует подтверждения)
- **explainFormula:** Объясняет формулу в ячейке
- **getSheets:** Получает список всех листов (бонус)

### Подтверждение записывающих действий
- **Двухэтапный процесс:**
  1. Модель вызывает `requestDangerousActionConfirmation` с `action: "updateXlsxCell"`
  2. Показывается UI с подтверждением
  3. При "Да" модель вызывает `performDangerousAction` с `action: "updateXlsxCell"`
  4. Ячейка обновляется и файл сохраняется

### Визуальное представление таблицы
- **SpreadsheetView:** Полная таблица с возможностью редактирования ячеек
- **TableMessage:** Мини-превью (первые 3 строки, 5 столбцов) с кликом для открытия модалки
- **Обрезка пустых строк/столбцов:** Функция `trimSpreadsheetData()` обрезает пустые "хвосты"

### Модальное окно
- **TableModal:** Полноэкранная модалка с таблицей
- **Выделение ячеек:** 
  - Клик для выделения одной ячейки
  - Drag для выделения диапазона
  - Визуальное выделение синим цветом
- **Формирование меншона:** Автоматическое формирование `@Sheet1!A1:B3` из выделенного диапазона

### Интеграция с агентом
- **System prompt:** Содержит инструкции для автоматического открытия таблицы
- **Контекст таблицы:** Сохраняется `lastSpreadsheetContext` для автоматического открытия при следующем запросе
- **Автоматический вызов:** При команде "открой таблицу" модель автоматически вызывает `getRange` с дефолтами или контекстом
